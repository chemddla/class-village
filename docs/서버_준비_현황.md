### 만들어 둔 스택: `class-village server`

- 구성: VM.Standard.A1.Flex (ARM), 1 OCPU / 6GB
- 운영체제: Canonical Ubuntu 24.04
- 네트워크: 새 VCN + 공용 서브넷
- 공용 IP: 생성 화면에서 켜지지 않아 **서버가 만들어진 뒤에 붙일 예정**
  - 서버 상세 → Networking → VNIC → IPv4 주소 → 편집 → 임시 공용 IP(Ephemeral public IP)
- 결과: Apply가 계속 **Out of capacity**(재고 부족)로 실패. 너무 자주 눌러서 **Too many requests**도 뜸.

### 다음 계획

1. 30분~1시간 뒤 **AMD Micro**(VM.Standard.E2.1.Micro, x86, Ubuntu 24.04)로 우선 서버를 만든다.
   - 메모리 1GB로 작지만 시험용·소규모 수업용으로 먼저 쓴다.
2. ARM(A1.Flex)은 **10분 이상 간격**으로 천천히 다시 Apply 한다. 자주 누르면 요청 제한에 걸린다.
3. 서버가 생기면: 공용 IP 붙이기 → 방화벽(보안 목록)에 443 열기 → Node.js 설치 → Caddy로 HTTPS 연결.

## 다른 컴퓨터에서 시작하기

Node.js 20 이상이 필요합니다 (이 컴퓨터는 v24).

```bash
git clone https://github.com/chemddla/class-village.git
```

```bash
cd class-village
```

```bash
npm install
```

```bash
npm run dev
```

- 게임 화면: http://localhost:5173
- 캐릭터 쇼룸: http://localhost:5173/character.html
- 가짜 학생 시험: `npm run bots -- 30`

## 이 컴퓨터에만 설치된 것 (다른 컴퓨터에서는 따로 설치 필요)

| 항목 | 용도 | 설치 방법 |
|---|---|---|
| Blender 4.5 LTS | `art/` 캐릭터 시안 만들기 | `winget install BlenderFoundation.Blender.LTS.4.5` |
| uv | Blender 연동(MCP) 실행 | `winget install astral-sh.uv` |
| MCP for Blender 추가 기능 2.3.1 | Claude가 Blender를 조종 | `uvx mcp-for-blender==2.3.1 install-addon` (Blender를 한 번 연 뒤 실행) |
| Python + Pillow | `art/make_sheet.py` 시안 한 장 합치기 | `pip install pillow` |

- Blender 연동은 사용 기록 전송을 끄고 쓴다: 환경 변수 `BLENDER_MCP_DISABLE_TELEMETRY=true`, Blender 추가 기능 설정의 사용 기록 동의 해제.
- 사용자 폴더 이름에 한글이 있으면 uv가 받는 파이썬 3.11 설치가 실패할 수 있다. 그때는 `UV_PYTHON_PREFERENCE=only-system`으로 이미 설치된 파이썬을 쓴다.
- Blender 연동 설정 파일(`.mcp.json`)은 이 컴퓨터의 경로가 들어 있어 저장소에서 뺐다. 다른 컴퓨터에서는 위 설치 후 `claude mcp add blender uvx mcp-for-blender==2.3.1` 로 다시 등록한다.
